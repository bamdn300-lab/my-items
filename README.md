家にあるIOT関連物にQRコードを貼りスマホにかざして情報を取得する。そのようなIOTのアイテム一覧。
1. モノのID,名前、対応ソフトのURLのリストを作成してgithubに登録してURLを取得する。
2. そのURLのQRコードをiPhoneの組み込みアプリ（ショートカット）で作成する。
3. QRコードを印刷し、モノに張り付ける。
4. モノの写真をとり、URLを取得し、そのURLにアクセスする。
